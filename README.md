# MKDotNet Project Template

An opinionated, engineering-first project template for creating maintainable, AI-ready software repositories.

## Purpose

This repository provides a minimal and reusable project foundation. It standardizes documentation, architecture guidance, AI bootstrap context, and repository conventions without imposing a runtime framework or SDK.

## Principles

- Documentation before implementation
- Simplicity over premature abstraction
- Human-readable and AI-readable project context
- Explicit architecture and decision records
- Testable and maintainable project structure
- Evolution based on real project needs
