# Project Roadmap

## Purpose

Milestone-level template evolution, not a task tracker. Adopting projects replace it with their verified roadmap.

## Foundation — Completed

- Documentation-first repository structure.
- Architecture/standards/ADR/RFC model.
- Shared AI bootstrap and review contract.

## Long-Lived AI-Assisted Maintenance — Completed

- Shared Codex/Claude Code/Cursor context model.
- Progressive context loading and debug/refactor routes.
- Graphify baseline plus optional Sourcegraph.
- Project-state, developer/user guide, module-context, conditional security, and repository-validation contracts.

## Implementation Isolation — Completed

- One `implementation/` boundary for the complete product workspace.
- Framework/project ownership of all internal implementation topology.
- Removal of generic root source/test/sample/tool placeholders.
- CI and Graphify routing based on the implementation boundary rather than `src/` assumptions.

## Future Evolution — As Needed

Add structure, vendors, automation, or governance only after recurring evidence from adopting projects demonstrates value.
